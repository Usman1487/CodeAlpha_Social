# E-Commerce Web Application - CodeAlpha Internship

A full-stack e-commerce web platform developed during the CodeAlpha internship, built with the MERN stack (MongoDB, Express.js, React, Node.js).

---

## Overview

This repository contains an end-to-end e-commerce application designed to provide essential online retail capabilities. The platform enables users to browse a product catalog, filter items by categories, view detailed product pages, manage an active shopping cart, and simulate a checkout workflow with secure backend order and user data persistence.

---

## Key Features

- **Product Catalog & Details:** Structured display of items with pricing, category tags, images, and full product descriptions.
- **Cart Management:** Add to cart, adjust item quantities, remove products, and dynamic order total calculations.
- **User Authentication:** Account registration and login powered by JSON Web Tokens (JWT) and encrypted passwords.
- **Search & Filter:** Category-based navigation and quick product search to streamline item discovery.
- **Checkout Process:** Structured checkout flow capturing shipping information and processing order placement.
- **RESTful API Architecture:** Scalable backend handling product CRUD, user accounts, and order records.

---

## Tech Stack

### Frontend
- **Framework:** React.js
- **Routing:** React Router DOM
- **State Management:** React Context API / useState & useReducer
- **Styling:** CSS3 / Modern Flexbox & Grid layouts
- **HTTP Client:** Axios / Fetch API

### Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB (via Mongoose ODM)
- **Security:** JSON Web Tokens (JWT)
